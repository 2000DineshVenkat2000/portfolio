03 / Selected work

Projects and engineering impact

Selected initiatives across Cyncly and Tiger Analytics — spanning enterprise data migration, cloud warehousing, data transformation, AI-enabled analytics, and measurable performance improvements.

PROJECT 01 · DATA PLATFORM

Near-real-time Data Migration & ELT Platform

A unified ingestion architecture for desktop and web product applications, plus API performance logs, landing data in ADLS Gen2 and loading curated data into Snowflake.

  • Built a single FastAPI POST endpoint to accept multiple business-object payloads, identify the object, validate its schema, and route the data.
  • Published sub-1 MB payloads to business-object-specific Azure Event Hubs; routed larger payloads directly to ADLS Gen2 as JSON.
  • Developed paired Azure Functions for Event Hub and Storage Account event triggers to process both paths and write Parquet files to the Raw / Bronze layer.
  • Built Spark, Pandas, and Dask transformations on Azure Synapse Spark Pools, followed by SQL- and Snowpark-based merges into Snowflake Silver tables every 4–6 hours.

PROJECT 02 · AI & BUSINESS ANALYTICS

Snowflake Natural Language Querying (NLQ)

Evaluated ways for business users to ask questions in natural language, generate SQL, execute it against Snowflake, and receive summarized or visualized results.

  • Built a PoC using Snowflake Cortex Analyst, semantic data models, and Cortex Agents.
  • Collaborated with AI Engineering to evaluate an in-house agent using the same semantic model.
  • Designed a Snowflake MCP Server with two tools: retrieve the semantic model as YAML and execute SQL queries with results returned to the client.
  • Compared solution costs, identifying approximately $0.45 per query for Cortex Agents versus $0.15 for the in-house solution, based on the evaluated setup.
  • Finalized a vendor-neutral MCP approach tested with Claude Desktop and OpenAI Codex, allowing users to use their preferred LLM tools and manage their own LLM costs.
  • Embedded workflow, dependencies, and execution guidance in tool descriptions to reduce additional prompt instructions.
Stack: Snowflake Cortex Analyst, Cortex Agents, MCP, Python, SQL, YAML, Claude Desktop, OpenAI Codex.
PROJECT 03 · CUSTOMER DATA SHARING

Snowflake Reader Account Administration

Administered dedicated Snowflake Reader Accounts for five Cyncly customers, enabling secure data sharing without requiring customers to maintain their own Snowflake accounts.

  • Provisioned and maintained customer-specific Reader Accounts.
  • Managed roles, warehouses, access configurations, and row-level security.
  • Provided ongoing operational support and access management for external customers.
Focus: Snowflake Reader Accounts, secure data sharing, role management, RLS, SQL.
PROJECT 04 · PERFORMANCE ENGINEERING

Snowpark Optimization for Power BI Refresh

Addressed slow and failing Power BI semantic model refreshes caused by complex Gold-layer business logic implemented in Snowflake views.

  • Investigated refresh bottlenecks in the Snowflake-backed Power BI data model.
  • Developed Snowpark Python optimization scripts to improve execution efficiency of the underlying transformations and queries.
  • Reduced refresh duration from approximately 90 minutes with repeated failures to 10 minutes with successful refreshes.

PROJECT 05 · TIGER ANALYTICS · LUXURY / FASHION

Data Transformation & Storage Optimization

Built data integration and transformation capabilities for a luxury-fashion client, supporting operational data marts, finance dimensional models, and store-traffic analytics.

  • Developed configuration-driven Azure Data Factory pipelines to extract historical and incremental data from on-premises SQL Server and Synapse Serverless SQL sources, landing the data in ADLS Gen2 as Parquet files.
  • Created Synapse Serverless SQL views to transform and serve Parquet data, then configured external tables in Azure SQL Database and stored procedures to incrementally load operational data marts.
  • Built Synapse Spark processing to retrieve store-traffic details from REST API endpoints, transform the data, and store it as Delta Lake tables in ADLS Gen2; orchestrated the job to run every 30 minutes.
  • Designed finance-detail dimensional models for Customer, Vendor, and Item Price modules, and developed fact and dimension tables in Delta Lake using historical and incremental Spark loads.
Stack: Azure Data Factory, Azure Synapse Analytics, ADLS Gen2, Azure SQL Database, Apache Spark, Delta Lake, Python, T-SQL, REST APIs, Git, Azure DevOps.
PROJECT 06 · TIGER ANALYTICS · DATA PLATFORM ACCELERATOR

Snowflake Data Fabric Accelerator

Contributed to an accelerator framework for automating Snowflake data transformations and continuously ingesting files from external stages into a Medallion architecture.

  • Developed automated dbt transformation pipelines for Snowflake objects.
  • Built a Python Snowpark framework to continuously load files as they became available in Snowflake external stages.
  • Implemented the ingestion and transformation flow to populate Bronze, Silver, and Gold layer tables.
Stack: Snowflake, dbt, Snowpipe, Snowpark Python, external stages, Git, GitHub.
PROJECT 07 · TIGER ANALYTICS · FINTECH

Cloud Data Warehouse & Migration

Worked across Software Engineer and Senior Software Engineer responsibilities to build and enhance an Azure Synapse-based cloud data warehouse and its historical and incremental ELT pipelines.

  • Built historical and incremental ETL pipelines to extract data from PostgreSQL and MongoDB, transform it using PySpark, and load it into the Azure Synapse Warehouse.
  • Designed and modelled the Synapse Data Warehouse and developed ELT pipelines, SCD Type 1 stored procedures, and materialized views.
  • Designed and developed a framework to monitor source schema changes using Azure Synapse and Azure Data Factory pipelines.
